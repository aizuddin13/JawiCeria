# Jawi Ceria

Game web untuk kanak-kanak belajar membaca Jawi: Kenal Huruf, Cari Huruf, Suku Kata dan Baca Perkataan.

- `index.html` — keseluruhan game (satu fail)
- `audio/` — rakaman suara (`.mp3`). Klip yang tiada akan diganti suara peranti secara automatik
- `senarai-rakaman.md` — senarai klip suara yang perlu dirakam

Buka `index.html` dalam pelayar, atau hos dengan GitHub Pages.
